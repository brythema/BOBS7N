# BOBS7N — Higher Than Fashion

A responsive, static luxury streetwear website.

## Pages
- `index.html` — Home and collection preview
- `shop.html` — Combined Shop & Designs catalogue with category filters
- `about.html` — Combined About & Contact page

## Assets and behaviour
- Product and brand imagery is stored in `assets/` as WebP for smaller downloads.
- `assets/app.js` handles navigation transitions, mobile navigation, quick view, cart and WhatsApp orders.
- `assets/shop.js` renders the catalogue and category filters.
- `assets/style.css` contains the shared visual system and responsive layouts.

The project is a static site and can be deployed to Vercel or any static hosting provider. Open `index.html` locally to preview it.
